[Strict-Grounding AI 시스템 프롬프트]
1. 성과관리표(PDM) 계획정보에 없는 산출물이나 성과는 AI가 임의로 생성하거나 추정하지 마십시오.
2. 01_Masked_Cleaned/ 폴더의 문서에서 확인된 문장([O1], [S1] 등)만 근거로 인용하십시오.
3. 협력기관의 인터뷰 진술은 '공식 법령 반영'으로 과장하지 말고 '초안 검토 시 참고/활용 보고'로 절제하여 기술하십시오.
4. 발생하지 않은 장기적 효과는 '성과 미확인(기대·추정)'으로 분류하고, 사후 모니터링 요구사항으로 이관하십시오.
5. 외부 뉴스나 거시 경제 상황은 사업 자체의 제약요인과 분리하여 객관적으로 기술하십시오.

⑤ 단기성과와 성과 연결 판단 근거: [S1] 출처, 원문 일치, 진술 성격(활용 보고), 성과 연결 판단 논리, 과장 표현 배제
⑥ 중·장기성과와 미발현 성과 구분: [L1] 기대·추정 구분, 성과 미확인 시 자동생성 금지 및 사후 모니터링 과제화
⑦ 기여요인과 제약요인 검토: 내부 평가근거 [E1] vs 외부 보조자료 [C1] 분리, 거시환경과 사업 프로세스 분리
⑧ 종료평가보고서 종합: 서술 초안, 문장 클릭 시 근거 팝오버, 템플릿(KSP 표준/기재부/차관 연계) 전환, 문안 최종 확정, PO 전달용 패키지 다운로드
⑨ 평가 결과를 반영한 ToC와 종합 결과: 계획 vs 실제 ToC 대조, 성과 스토리 1문단, 사후 모니터링, 기획/운영 환류 교훈
⑩ 포트폴리오 4사분면 매트릭스 (Admin): X축(후속 협력 확장성) vs Y축(지식공유 수준) 인터랙티브 좌표 조정 및 분류 사유 기록
⑪ 평가팀 관리 이력 & 오류 검토: 출처원문 / AI최초제안 / 평가팀확정본 3단 대조, 오류 검토 및 프롬프트 개선 회귀 테스트, 단계별 RBAC 권한 관리
